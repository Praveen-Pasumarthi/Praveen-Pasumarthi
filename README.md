### What I build

I like turning small ideas into complete app experiences: mobile games, physics puzzles, AI-assisted fitness tools, and interactive web experiments. My work usually sits at the intersection of clean UI, real-time interaction, and practical product polish.

- Building mobile-first products for iOS and Android
- Exploring game mechanics, procedural levels, physics, and tactile controls
- Working with Flutter, React Native, Expo, Unity, Flame, Skia, and TypeScript
- Improving projects from prototype to something people can actually use

### Featured work

| Project | What it is | Stack |
|---|---|---|
| Milk-A-Way | Gravity-based puzzle game with procedural levels, custom level tooling, and mobile builds | Flutter, Flame |
